# 黑屏守护应用图标

使用内置 imagegen 生成，设计为深色显示器与蓝色锁，透明背景，不含文字。

- 原始图：`app-icon.png`
- Windows 多尺寸图标：`app.ico`，16、20、24、32、40、48、64、96、128、256 像素。
- `build-icon.ps1` 仅转换格式和生成各尺寸，保留原图透明通道。

生成提示词：

```text
Use case: logo-brand. Asset type: final Windows desktop application icon for 黑屏守护, a black-screen privacy guard utility. Create one polished square app icon, 1024x1024 composition, with genuinely transparent outer corners/background. A bold dark charcoal rounded-square tile with a subtle midnight-blue edge, containing a single simplified front-facing black computer monitor and a clear electric-blue closed padlock centered on the screen. Minimal sculpted depth, clean precise geometry, thick readable shapes, balanced centered composition, very limited palette of charcoal, blue and a tiny pale highlight. The padlock should be the unmistakable focal point and remain readable as a tiny 16px taskbar icon. Monitor bezel and short stand visually simple. Tile fills about 90% of the square. No letters, no words, no keyhole micro-details, no fine linework, no shield, no decoration, no background scene, no mockup, no extra icons, no watermark. Professional native desktop utility appearance.
```
